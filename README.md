# AI-Based Laser Security System

## Overview

The AI-Based Laser Security System is an intelligent intrusion detection system that combines laser sensors, computer vision, and machine learning to provide enhanced security monitoring.

When a laser beam is interrupted, the system activates a camera and uses a YOLO-based AI model to identify whether the detected object is a human, animal, or vehicle. If an unauthorized person is detected, an alarm is triggered and an alert is sent to the owner.

## Features

- Laser-based intrusion detection
- Real-time object detection using YOLOv8
- Human recognition
- Intruder image capture
- Alarm activation
- Email/Telegram notifications
- Event logging

## Technologies Used
